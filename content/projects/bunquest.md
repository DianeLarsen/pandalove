## Project goals

Make it easier to begin small, real tasks on difficult days without turning self-care into a surveillance program with confetti.

## Core features

- Daily quest suggestions shaped by a selected bun persona.
- Custom quests with notes, subtasks, rescheduling, and recurrence.
- A gradual profile so suggestions can become useful without making setup feel like filing taxes.

## Next steps

Finish the profile and quest data model, then build the adaptive daily selection flow.
